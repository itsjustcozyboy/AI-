# AI 활용 기록

이번 작업: 2026-10-21 (작업 환경의 UTC 날짜), OpenAI Codex. 시스템에서 확인 가능한 모델 계열은 GPT-6이며 세부 배포 모델명은 확인되지 않아 기재하지 않는다. 이전 작업의 서비스·모델·사용일·사람 검토 내역은 사용자 확인 필요.

대표 프롬프트: 기존 `../../CODEX_PROMPT.md` 보존. 이번 대화의 “서울 시내버스 전 문 승차 분석 — 공모전 제출 전 보완” 요청은 분석 저장소 보완, 하차 고려 정책, 민감도·악화 셀 공개, 보고서 근거 생성을 지시했다. 전체 이번 프롬프트의 별도 파일 저장 여부는 사용자 확인 필요.

이번 Codex는 저장소·공식 출처 탐색, 코드 작성, 고정 환경 설치, 모형 계산·테스트 실행, 원본 해시 확인, CSV와 한글 그림 생성, 문서화를 수행했다. AI가 자동 실행한 검사는 인간의 검토 또는 실측 정책 검증이 아니다. 사람이 AI 제안을 수정·제외한 이력은 현재 대화에서 확인되지 않으며 사용자 확인 필요다.

확인한 문제: 기존 민감도는 정차횟수의 대수적 상쇄를 넘어서는 후보 안정성 정보가 부족했고 상세 셀은 수요 상위 30개만 공개했다. 처리 모수 출처표와 하차 고려 정책·한글 그림도 없었다. 기존 음수 결과 보존과 가정 표시를 유지했다. 시작 시 이미 존재하던 보완 코드와 문서를 보존했다. 이번 실행에서는 Python 3.12의 `venv --without-pip`로 `/tmp/seoul-submission-venv`를 새로 만들고, 기존 bootstrap pip로 고정 의존성을 설치했다. 샌드박스 DNS 실패 후 승인된 네트워크에서 설치했다. 이전 환경 생성 실패에 관한 기존 기록은 이번에 재현하지 않았다.

검증 주체: Codex 자동 검사—입력 SHA-256, 원본 전처리 품질, 수식 예시, 정책 미적용 동일성, 분모·합계, 실행 설정 및 출력 해시. Codex 그림 직접 열람—한글·단위·범례·잘림. 연구자/사용자—자료 사용 적합성, 정책 타당성, 출처와 최종 보고서 검토는 아직 확인되지 않았다. 검사 결과는 `verification.md`에 기록한다.
