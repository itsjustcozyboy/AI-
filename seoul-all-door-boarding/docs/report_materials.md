# 분석보고서 작성용 근거 묶음

최종 DOCX/PDF가 아니다. 본문 약 5장 구성에 사용할 수치·그림·출처를 연결한 문서다. 공식 공지의 2026년 10월 22일 마감을 2026-10-21 UTC에 재확인했다. 마감 시각은 미확인이다. 붙임2 링크의 웹 열람은 Internal Error로 실패했고 작업 공간에 양식 파일이 없어 사용자 제공 요구사항을 사용했다. 보이지 않는 서식은 추정하지 않았다.

## 1. 연구 제목과 요약

**서울 시내버스 승하차 수요 기반 선택적 전 문 승차 시범지역 선정 및 정책 시나리오 분석**

서울시 2026년 9월 카드 집계로 현장 검토 대상을 찾고, 하차 후 뒷문 승차라는 가정 모형으로 다섯 정책을 비교한다. 수요 집중을 병목으로, 모형 시간을 실측 효과로 해석하지 않는다. 전면 확대보다 승하차 구성을 고려한 선택적 검토의 필요성을 탐색하며 불리한 셀과 가정별 순위를 공개한다. 결과 수치는 아래의 자동 생성 요약을 기준으로 인용한다.

## 2. 문제 정의와 분석 범위

연구 질문은 어느 정류장·노선·시간대가 검토 대상이며 어떤 승하차 조건에서 유리하거나 불리한가이다. 간선 010·지선 020·순환 040을 포함하고 마을·광역·심야 등을 제외한다. 서울버스의 시외 정류장 가능성을 포함하며 행정경계 필터는 없다. 앞문·뒷문의 2문 처리 모형이며 실제 저상·굴절·문 구조·차종은 확인하지 못했다. 관측 단위는 월·노선·원문 정류장 표기·표준 ID·교통수단·시간대 집계로 차량 정차가 아니다.

## 4. 분석 방법과 모수 근거

[방법론](methodology.md), [모수 근거표](parameter_evidence.csv), `config/scenarios.yaml`, `config/settings.yaml`을 함께 인용한다. 모든 처리시간·간섭·혼잡·분산 비율은 실측 미보정 가정이다. 카드 태그와 문별 이동은 별개이며 합계가 승차 처리시간이다. 해외 평가의 승하차당 체류시간을 태그시간으로 대체하지 않았다.

현행·제한 뒷문·전 문 확대·피크 선택·하차 고려 선택을 같은 전체 모집단에서 비교한다. 하차 고려는 월 하차/승차 ≤ .5, 가정 혼잡 ≤ .3, 뒷문 .35이며 현장 최적값이 아니다. 한 요인 16회와 복수 요인 4회를 기준과 비교한다. 운행횟수 3·12회 점검 2회는 대수적 상쇄 확인으로 독립 민감도 증거에서 제외한다. 원본→전처리→전체 분석→그림→검증·내보내기를 새 환경에서 실행한다.

## 5. 관측 결과

[검증 수치와 정책 표](results_submission_20261021/summary.md)의 관측 부분, `quality_report.json`, `hourly_demand.csv`, `top_stops.csv`를 인용한다. 승차 117,203,508건, 하차 115,040,868건은 분석 범위 월 카드 건수이며 사람 수가 아니다. 최다 승차 정류장 홍대입구역 [113000422]의 월 승차 330,215건은 수요 집중이며 지연 증거가 아니다.

## 6. 가정 기반 정책 비교와 후보

[전체 정책 비교 CSV](results_submission_20261021/policy_comparison.csv)와 [자동 생성 요약](results_submission_20261021/summary.md)을 사용한다. 본문은 reference 한 설정을 비교하고 나머지는 민감도 표로 별도 제시한다. 시간 단위는 조건부 차량 초/달력일이며 표에서는 3,600으로 나눠 시간/일로 표시한다. 악화 셀 수와 전체·실제 적용 분모를 혼동하지 않는다.

상위 K, 중복률, 포함 횟수, 순위 범위, 부호 전환은 `top_k_by_setting.csv`, `rank_overlap.csv`, `candidate_stability.csv`, `sign_flip_candidates.csv`다. K=10, 동점은 ID 오름차순, 후보 수가 K 미만이면 전부다. 정책이 꺼져 모든 점수가 0인 설정은 ID 동점 순위일 뿐 유효한 우선순위가 아니다. 포함 빈도는 탐색 설정 비율이며 통계적 확률이 아니다. 별도 기간 검증은 없다.

전체 정류장·정책 합계는 `outputs/submission_20261021/stop_policy_summary.csv.gz`, 기준 전체 셀은 `cells/reference_*.csv.gz`다. 다른 설정 셀 파일은 각 설정 상위 K 정류장의 모든 셀에 한정한다. 공개용 상위 3곳의 상세 범위는 `results_submission_20261021/pilot_operating_cells.csv`, 노선·시간은 `pilot_route_hours.csv`다. 방향·위치 등 현장 검증 전 후보이며 순위는 도입 확정이 아니다.

## 7. 시범 운영 제안·한계·추가 검증

[시범 운영 설계안](pilot_design.md)을 사용한다. 하차 우선·경사판 공간·대기열 분리·단말기와 환승 정산 시험이 선행 조건이다. 유사 대조군과 전후 이벤트 측정으로 시간·안전·접근성·요금관리 평가를 제안한다. 표본 수·비용·정량 효과 목표는 실측 분산과 협의 후 결정한다. 취약계층 편익, 버스 몰림 감소, 증회·감차, 탄소·금전 편익은 현재 자료로 입증하지 못했다.
