# 연구 질문별 달성 범위

| 질문/산출물 | 현재 구현·실행 | 남은 증거와 해석 제한 |
|---|---|---|
| RQ1 수요 분포 | 공식 월별 승하차 전처리, 6개 EDA CSV/그림, 물리적 정류장 수요 순위 | 날짜·요일·행정경계·실측 지연 없음. 수요 후보이지 병목 확정 아님 |
| RQ1 수요-체류 관계 | 실제 이벤트 입력·검증·동일 단위 집계·WLS 고정효과 및 군집 구간 코드, 합성 단위시험 | 실제 이벤트 미확보로 실증 추정 미실행 |
| RQ2 문별 처리 | 4정책 × 3조건 × 3운행빈도, 고정·승하차·병렬·간섭·혼잡·도움 시간, 손실 허용 | 모수 모두 가정. 현장 문별 승하차·차량 부하로 보정 필요 |
| RQ3 노선 누적 | 관측 활동 셀의 조건부 일일 절감, 이벤트당 평균 절감 | 회차·방향별 순서·실제 운행횟수 없음. 1회/왕복 절감·증회/감차 미산출 |
| RQ4 배차 안정성 | 실제 이벤트가 있을 때 방향·운행일별 평균/표준편차/CV/공백/연속 도착 지표 코드 | 관측 자료 없음. 정책 후 배차 시뮬레이션은 동적 운행모형 및 보정 자료 확보 후 구현해야 함 |
| RQ5 우선 후보 | 선택적 정책 가정 최소 절감·수요로 현장 검증 후보 CSV | 비용·안전·접근성 점검 전 최종 시행 우선순위 확정 불가 |
| 환경·경제성 | 명시적 출처/계수 입력을 요구하는 조건부 계산 함수, 미확인 비용 평가표 | 재차인원·시간가치·차종별 에너지 계수·견적 미확보로 실제 편익/비용비·CO2 미산출 |
| 재현성 | 원본 보존, 출처 HTML/manifest, SHA-256, 버전 잠금, 실행 명령, 단위·통합시험 | 파일 제공기관의 향후 개편 시 공식 폼 재확인 필요 |

## 전제 검증을 위한 후속 자료

1. 동일 시점의 정류장 좌표·표준 ID·ARS crosswalk와 노선번호↔BIS ID·방향·정류장 순서.
2. 월 전체 운행횟수 또는 일별·시간대별 완전한 차량 이벤트, 문 개폐 기준과 누락률.
3. 현장 승하차 처리시간 및 문별 실제 선택률, 혼잡·이동약자·만차 미승차 표본.
4. 디젤/CNG 공회전 실험 계수 또는 전기 보조부하, 실제 시간표 변화 여부.
5. 단말기 호환성과 설치·검표·유지비 견적, 환승 정산 담당기관 검토.

요청문의 디렉터리 목록은 `tests/test_pre`에서 끝났다. 원문은 루트 `CODEX_PROMPT.md`에 받은 범위까지만 보존했으며, 이후 미전달 요구사항이 있다고 가정해 생성하지 않았다.
